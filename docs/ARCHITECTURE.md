# 구현 구조

## 편집기

`web/chrome.jsx`의 React 헤더/도구와 `web/flow-editor.jsx`의 카드 편집기는 shadcn/ui Button과 Tailwind 토큰을 사용합니다. 전역 내비게이션은 내 루틴 / 모두의 루틴이고, 편집기는 선택한 루틴의 하위 경로입니다. `web/experience.css`는 공통 화면 구성과 차량용 터치 크기를 정의합니다. 기존 v1 JSON 연결 형식을 유지합니다.

Asta Sans를 로컬 번들에 포함합니다. 흐름은 HTML 카드와 CSS 연결선으로 표현하며 모바일에서 세로로 재배치합니다. 값 편집과 동작 추가는 필요할 때 대화상자로 엽니다. 메뉴와 키보드로 순서를 바꾸거나 데스크톱에서 다른 분기로 드래그할 수 있습니다.

편집 변경은 복사본을 검증한 뒤 반영합니다. 시작/분기/반복의 연결과 고유 ID를 보존하고, 자신 안으로 이동하는 순환 연결은 거부합니다. 최근 60번의 변경을 실행 취소/다시 실행할 수 있습니다.

## 실행

`web/runtime.js`가 블록 데이터를 직접 해석합니다. JavaScript 코드 생성, eval, 가져온 스크립트 실행은 없습니다. 값 타입, 허용 블록, 연결 깊이, 파일 크기를 검증합니다.

- 파일 500,000자 이하, 루틴 이름 80자, 블록 500개, 깊이 80.
- 실행 한 번에 최대 30초 / 1,000단계, 반복 최대 100회.
- 실행 중 편집 잠금, 중지 시 대기·음성·네이티브 요청 취소.
- 입력 데이터는 실행 시 스냅샷, 어댑터 오류에는 실패 블록 ID 표시.

브라우저에서는 차량 실행과 감지를 비활성화하고 ON/OFF 사용 설정만 저장합니다. Android 앱은 네이티브 브리지의 실제 응답을 사용하고 미지원·권한 오류를 표시합니다. `web/foreground-automation.js`는 ON인 각 루틴의 스냅샷과 구독 토큰을 별도로 관리하며 앱 내부 화면 이동과 독립적으로 감지합니다. OFF·삭제·변경 시 해당 토큰만 해제하고 늦게 도착한 콜백은 무시합니다. 등록 도중 OFF가 되어도 등록 완료 후 다시 해제합니다. 상태형 스트림은 첫 값을 기준으로 삼고, 일회성 연결 이벤트는 첫 값부터 처리합니다.

실행기는 한 번에 하나의 루틴만 실행하며 기록·변수·결과는 루틴별로 보관합니다. 실행 중 일반 이벤트는 건너뛰고 Gleo STOP 요청은 실행 취소 후 처리합니다. 네이티브 실행 취소는 실행 요청만 취소하며 다른 루틴의 진행 중인 감지 등록을 취소하지 않습니다. 앱 일시 중지는 감지·실행을 중지하고 ON 설정은 보존합니다. 복귀 시 구독과 기준값을 새로 연결합니다. 블록 편집은 해당 루틴을 OFF로 바꿉니다. 새 루틴·복제·가져오기 및 사용 설정이 없던 기존 v1 루틴은 OFF로 시작하며 로컬 `enabled` 설정은 내보내기·공유에 포함하지 않습니다.

## 저장과 가져오기

브라우저 localStorage / Android 전용 SharedPreferences에 0~50개 루틴을 저장합니다. 처음 실행할 때 예제를 자동으로 저장하지 않고, 기존 v1 저장본은 그대로 읽습니다. 가져올 파일·JSON을 검증한 뒤 새 루틴을 생성하므로 잘못된 파일이 기존 루틴을 지우지 않습니다. 가져온 루틴은 자동 실행하지 않습니다. 파일 백업과 사용자 게시물 공유는 별도의 흐름입니다. 공유 게시물은 로컬 서버에 저장합니다.

## Android

`MainActivity.kt`의 WebView는 패키지 내부 `appassets.androidplatform.net/assets/editor/`만 제공합니다. 외부 요청·탐색·임의 파일 접근을 차단하고 CSP를 적용합니다. 제한된 bridge가 저장, 차량 API, TTS, 파일 가져오기·내보내기를 처리합니다. 가져오기는 시스템 문서 선택기로 사용자가 선택한 파일만 500KB 이내에서 읽어 데이터로 전달합니다. 앱이 배경으로 이동하면 실행/이벤트/TTS를 정지합니다.

이전 조회 앱은 `DiagnosticsActivity.kt`로 보존했습니다. preBuild가 Vite를 실행해 같은 프런트엔드를 APK에 묶습니다. Pleos 런타임 검증은 브라우저 검증과 별도로 기록합니다.
