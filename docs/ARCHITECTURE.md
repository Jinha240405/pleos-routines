# 구현 구조

## 편집기

`web/chrome.jsx`의 React 헤더/도구와 `web/flow-editor.jsx`의 카드 편집기는 shadcn/ui Button/Tabs와 Tailwind 토큰을 사용합니다. `web/style.css`, `web/flow.css`가 색상·서체·간격을 공유합니다. Blockly 렌더러와 의존성을 제거했으며, 기존 v1 JSON 연결 형식을 유지합니다.

Pretendard GOV v1.3.9를 로컬 번들에 포함합니다. 흐름은 HTML 카드와 CSS 연결선으로 표현하며 모바일에서 세로로 재배치합니다. 값 편집, 동작 추가, 테스트 설정은 필요할 때 대화상자로 엽니다. 메뉴와 키보드로 순서를 바꾸거나 데스크톱에서 다른 분기로 드래그할 수 있습니다.

편집 변경은 복사본을 검증한 뒤 반영합니다. 시작/분기/반복의 연결과 고유 ID를 보존하고, 자신 안으로 이동하는 순환 연결은 거부합니다. 최근 60번의 변경을 실행 취소/다시 실행할 수 있습니다.

## 실행

`web/runtime.js`가 블록 데이터를 직접 해석합니다. JavaScript 코드 생성, eval, 가져온 스크립트 실행은 없습니다. 값 타입, 허용 블록, 연결 깊이, 파일 크기를 검증합니다.

- 파일 500,000자 이하, 루틴 이름 80자, 블록 500개, 깊이 80.
- 실행 한 번에 최대 30초 / 1,000단계, 반복 최대 100회.
- 실행 중 편집 잠금, 중지 시 대기·음성·네이티브 요청 취소.
- 입력 데이터는 실행 시 스냅샷, 어댑터 오류에는 실패 블록 ID 표시.

시뮬레이션 어댑터는 테스트 데이터만 바꿉니다. Android 연결 모드에서 운전석 도어 이외의 미지원 값은 오류를 표시합니다. 가짜 차량 응답으로 대체하지 않습니다. 이벤트는 사용자가 활성화한 상태에서 현재 화면의 테스트 입력을 바꿀 때만 실행됩니다.

## 저장과 가져오기

브라우저 localStorage / Android 전용 SharedPreferences에 최대 50개 루틴을 저장합니다. 가져올 JSON을 검증한 뒤 새 루틴을 생성하므로 잘못된 파일이 기존 루틴을 지우지 않습니다. 가져온 루틴은 자동 실행하지 않습니다. 공유 기능은 JSON 복사/파일 저장이며 서버 업로드는 없습니다.

## Android

`MainActivity.kt`의 WebView는 패키지 내부 `appassets.androidplatform.net/assets/editor/`만 제공합니다. 외부 요청·탐색·파일 접근을 차단하고 CSP를 적용합니다. 제한된 bridge가 저장, 도어 조회, TTS, 파일 내보내기를 처리합니다. 앱이 배경으로 이동하면 실행/이벤트/TTS를 정지합니다.

이전 조회 앱은 `DiagnosticsActivity.kt`로 보존했습니다. preBuild가 Vite를 실행해 같은 프런트엔드를 APK에 묶습니다. Pleos 런타임 검증은 브라우저 검증과 별도로 기록합니다.
