## 이 프로젝트의 데모 방향

운전자가 차량 상태를 읽고 조건·반복·변수로 자신만의 루틴을 만드는 제작 도구입니다. 테스트 데이터와 실제 Vehicle SDK 응답을 화면에서 구분합니다. 시뮬레이션 공조를 실제 차량 제어로 소개하면 안 됩니다.

발표 예시: 온도 분기 → 배터리 기준 변수와 반복 알림 → 도어 이벤트 → JSON 내보내기. 수익·사용자 수·절감 효과는 검증 전 가설로 구분합니다. 정차 중 편집, 실행 취소, 오류 처리와 지원 API 범위를 함께 보여줍니다.
