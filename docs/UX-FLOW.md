# 내 루틴과 모두의 루틴

## 화면 관계

- 전역 메뉴: 내 루틴 / 모두의 루틴.
- 기본 진입: 내 루틴. 저장한 루틴과 공식 템플릿을 구역으로 구분한다.
- 편집: 내 루틴 → 루틴 선택 → 이름·저장 상태·요약·카드 흐름. ‘내 루틴’으로 돌아가기와 브라우저/차량 뒤로 가기를 지원한다.
- 모두의 루틴: 사용자 공유 게시물만 제공한다. 공유할 저장 루틴을 먼저 선택한다. 편집기의 ‘이 루틴 공유’는 해당 루틴을 명시적으로 선택한다.

## 생성·보관

첫 방문과 마지막 루틴 삭제 후에는 빈 상태를 표시한다. 예제나 빈 루틴을 자동 생성하지 않는다. 기존 v1 저장 데이터는 이름·ID·블록을 유지한다.

공식 템플릿을 누르면 시작 방식, 조건, 동작, 사용 기능, 조정할 값을 먼저 확인한다. ‘이 템플릿으로 만들기’에서만 사본을 저장하고 편집 화면을 연다. 목록 카드에는 동작 요약을 표시하며 복제·공유·삭제는 더 보기 메뉴에 둔다. 수동 루틴은 차량 앱에서 카드의 실행 버튼으로 사용할 수 있다.

## 실행과 감지

저장과 실행은 별도 상태다. 시작 방식은 ‘버튼을 눌러 시작 / 상태가 바뀌면 시작’으로 고르고, 감지형은 다음 단계에서 상태 종류를 정한다. 기존 routine_start / routine_event / routine_api_event 데이터 형식은 유지한다.

각 저장 루틴에 ON/OFF 스위치를 제공하고 기기에 사용 설정을 저장한다. OFF면 수동 실행과 감지를 막고 진행 중인 해당 루틴의 실행도 취소한다. 수동 루틴을 ON으로 켜는 것만으로 실행하지 않는다. 새 루틴·템플릿 사본·복제·파일/공유 가져오기는 OFF로 시작하며, 사용 설정이 없던 기존 v1 데이터도 OFF로 읽는다. 블록을 수정하면 OFF로 바꾸고 다시 켜도록 안내한다.

`ON · 감지 연결 중`, `ON · 상태 감지 중`, `ON · 직접 실행 대기`, `OFF`, 실행 결과를 구분한다. 여러 ON 루틴은 현재 편집하는 루틴과 독립적으로 감지하며 앱 안에서 화면을 이동해도 유지한다. 실행은 한 번에 하나만 진행하고, 실행 중 들어온 일반 이벤트는 건너뛰며, Gleo 중지 요청은 현재 실행 취소 후 처리한다. 앱 일시 중지는 실행과 감지를 멈추지만 ON 설정은 보존한다. 복귀 시 새 기준값을 받은 뒤 이후 변화를 감지한다. 백그라운드 자동화는 제공하지 않는다. 웹에서는 설정을 저장할 수 있으며 차량 실행·감지 연결은 제공하지 않는다.

## 파일과 공유

파일 선택이 기본 가져오기 동선이며 JSON 직접 입력은 고급 항목이다. 선택한 파일을 검증하고 사용자가 ‘새 루틴으로 가져오기’를 눌렀을 때만 추가한다. Android도 사용자 문서 선택기로 같은 흐름을 제공한다. 파일·공유에서 가져온 루틴은 실행이나 감지를 자동 시작하지 않는다.

자동저장, 실행 취소·다시 실행, 입력 검증, 실행 오류 위치와 세부 기록은 유지한다. 웹과 Android는 동일한 UI 소스를 사용하며 화면 폭과 차량 모드에 맞춰 간격·터치 크기를 조절한다.
