# 디자인 시스템 · 0.3

화면을 차량 자동화용 카드 편집기로 재구성했습니다. 구체적인 레이아웃 결정은 [CARD-EDITOR.md](CARD-EDITOR.md)에 있습니다.

## 레이아웃

- 1440px: 64px 내비게이션, 100px 프로젝트 도구, 최대 1040px 폭의 중앙 흐름 영역.
- 오른쪽 상시 패널과 왼쪽 블록 팔레트 제거. 파일 / 테스트 설정 / 실행만 주요 도구로 둡니다.
- 시작 카드 → 조건 카드 → 조건 충족/미충족 분기 → 다음 단계. 조건 두 갈래가 끝나면 연결선으로 다시 합쳐집니다.
- 카드에는 아이콘·이름·현재 값만 표시. 설정은 카드 클릭, 추가는 흐름 끝 버튼, 정렬·복제·삭제는 카드 메뉴와 드래그로 처리합니다.
- 375px: 프로젝트 도구 한 줄, 조건 분기 세로 정렬, 테스트 대화상자 한 열. 페이지 가로 넘침 없음. 긴 흐름은 세로 스크롤합니다.

## 색상과 구성 요소

| 역할 | 색상 |
| --- | --- |
| 카드 / 헤더 | #FFFFFF |
| 작업 배경 | #F7F8FA |
| 본문 | #253041 |
| 보조 글자 | #626D7D |
| 주요 동작 / 포커스 | #2563EB |
| 옅은 강조 | #EFF4FF |
| 경계 | #E3E7EC |

React, shadcn/ui Button/Tabs와 Tailwind 토큰을 사용합니다. 카드 반경 12px, 대화상자 16px, 입력 높이 44px. 퍼즐 돌기·모자·알약 입력·카테고리별 무지개 채움을 제거했습니다. 프로젝트 로고도 연결 경로 형태로 변경했습니다.

## 한글

Pretendard GOV v1.3.9를 로컬에 포함했습니다. 본문 17px, 카드 제목 16px, 카드 설명 15px, 값 20px, 메타데이터 13px. 폼 입력 16px, 제목 20~24px. 한글 어절 줄바꿈, 긴 문자열 강제 줄바꿈, 1.5 이상의 본문 행간을 유지합니다. 블록 배율에 따라 글자가 줄어드는 방식은 제거했습니다.

초기 조사에서 참고한 자료:
- KRDS 타이포그래피: https://www.krds.go.kr/html/site/style/style_03.html
- Material 3: https://m3.material.io/styles/typography/applying-type
- Radix 색상 체계: https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette

정부 디자인 시스템 전체 준수나 접근성 인증을 주장하지 않습니다. 역할별 크기는 편집기의 정보 밀도에 맞게 조정했습니다.

## 검증

기본 구조, 편집/추가/테스트, 긴 텍스트/메뉴/오류를 3차례 촬영했습니다. 마지막에는 모바일 대화상자 여백과 중첩 반복 흐름을 별도로 확인했습니다. 원본은 artifacts/cards-round-* 및 artifacts/cards-final, 대표 캡처는 screenshots/에 있습니다.
