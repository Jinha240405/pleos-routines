# 차량 루틴 카드 편집기

2026-11-02 후속 디자인. 기존 퍼즐 블록의 학습용 인상을 줄이고 차량 자동화의 흐름을 읽는 화면으로 바꾼다.

## 레이아웃과 시각 규칙

- 상단: 앱 내비게이션, 루틴 이름과 저장 상태, 파일 / 테스트 설정 / 실행. 새 루틴은 보관함에서 만든다.
- 본문: 전체 너비의 밝은 회색 작업 영역, 최대 960px의 중앙 흐름. 왼쪽 도구 상자와 오른쪽 상시 패널은 제거한다.
- 시작·조건·동작을 흰색 카드와 1px 연결선으로 표현한다. 퍼즐 돌기, 모자, 알약 모양 값 블록, 무지개색 채움을 사용하지 않는다.
- 카드에는 작은 단색 아이콘, 동작 이름, 현재 값만 둔다. 파랑은 실행 버튼, 포커스, 실행 단계와 작은 아이콘에 사용한다.
- 조건은 조건 카드 아래 두 갈래로 나누고 충족 / 미충족을 글자로 표시한다. 모바일 375px에서는 세로로 정렬한다.
- 본문 17px, 동작 제목 16px, 설명 15px, 보조 레이블 13px. 한글 어절 줄바꿈과 충분한 행간을 유지한다.
- 설정은 카드 클릭으로 여는 대화상자에서 수정한다. 추가는 흐름 끝의 버튼, 재정렬은 드래그와 위/아래 버튼, 삭제는 실행 취소로 복구한다.
- 테스트 입력·SDK 연결·실행 기록은 필요할 때 여는 대화상자에 모은다. 실행 상태와 결과 열기만 편집기에 남긴다.

## 기능과 호환성

기존 루틴 JSON, 실행 엔진, 네이티브 브리지와 저장 형식을 유지한다. 조건·반복·변수·중지·취소를 카드로 편집한다. 실행 중 편집은 잠근다. 화면을 줄이거나 모달을 닫아도 편집 내용은 유지한다.

## 검증

1440×960 / 375×812의 기본 화면 → 추가/편집/테스트/오류 상태 → 긴 텍스트·중첩 조건·키보드·정렬을 세 차례 이상 실제 Playwright 캡처로 확인한다. 엔진, 사용자 편집 동작, 오프라인 CSP와 APK 빌드를 별도로 확인한다.
